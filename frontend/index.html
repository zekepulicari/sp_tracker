Resources

Technologies, APIs, and data sources powering Species Tracker.

  • iNaturalist API — Real-time biodiversity observations and density grid tiles api.inaturalist.org ↗
  • Leaflet.js — Interactive map rendering, markers, and popups leafletjs.com ↗
  • CARTO Basemaps — Light basemap tiles for the default map layer carto.com ↗
  • Esri World Imagery — Satellite imagery for the alternate map layer arcgis.com ↗
  • FastAPI — Python backend framework serving the API proxy fastapi.tiangolo.com ↗
  • HTTPX — Async HTTP client for server-side API requests python-httpx.org ↗
  • cachetools — In-memory TTL caching for API responses pypi.org ↗
  • Inter (Google Fonts) — Modern sans-serif typeface used across the UI fonts.google.com ↗
